### How to use
### English Version

1. **Create Sources**:
* Add a **Text** source and name it `text_count`(you can change name).
* Add an **Image** source and name it `img` (leave the image and text fields blank).


2. **Load Script**:
* Go to **Tools** > **Scripts**.
* Click **`+`** and select the `.lua` script file.


3. **Configure Script Settings**:
* In the script window, enter the exact names you created in Step 1: `Count` for the text source and `img` for the image source (case-sensitive).
* Select your **Idle** and **Pressed** images.


4. **Set Hotkey**:
* Go to **Settings** > **Hotkeys**.
* Look for **"Counter Hotkey"**.
* Press your desired key combination (e.g., `Ctrl+Z`), then click **Apply / OK**.
